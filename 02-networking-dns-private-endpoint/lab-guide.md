# Lab 02 - Azure Networking & Private Endpoint

## Objective
Secure Azure resources using Private Endpoint and DNS.

## Steps

1. Create Storage Account
2. Disable Public Access
3. Create Private Endpoint
4. Link to Virtual Network
5. Create Private DNS Zone:
   - privatelink.blob.core.windows.net
6. Link DNS Zone to VNet

## Outcome
- Secure internal access to storage

## Skills
- Azure Networking
- DNS
- Private Endpoints
